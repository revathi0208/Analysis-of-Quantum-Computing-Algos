The Problem: The Two-Coin Test

Black-Box Challenge

You are given a mystery black box. You feed in an input, and it gives back 0 or 1. The box is guaranteed to be strictly one of two kinds:

1. Constant (Trick Coin)

Always 0 or Always 1

Every single input gives the exact same output bit. Like a two-headed coin.

2. Balanced (Fair Coin)

50% 0s and 50% 1s

Exactly half the inputs return 0, and the other half return 1. Like a fair coin flip.
